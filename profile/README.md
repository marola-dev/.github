# 🌊 marola

A friendly guide to the sea near you, built in the open as citizen science. marola ranks nearby
beaches for swimming from live sea and weather data and official bathing-water quality, with a
deterministic safety veto and an LLM summary checked by a second pass. It runs locally on a free
Ollama model.

- **[marola.dev](https://marola.dev/)**: the live map.
- **[docs.marola.dev](https://docs.marola.dev/)**: using, building and working on marola.

| Repo | What it holds |
|---|---|
| [marola](https://github.com/marola-dev/marola) | The umbrella: the docs site, the MIPs, the ways of working, every repo as a submodule |
| [marola-app](https://github.com/marola-dev/marola-app) | The product: Scala 3 + Kyo, the CLI and the MCP server |
| [marola-site](https://github.com/marola-dev/marola-site) | The map at marola.dev |
| [marola-corpus](https://github.com/marola-dev/marola-corpus) | The sourced ocean knowledge marola answers from |
| [marola-ml](https://github.com/marola-dev/marola-ml) | Prompt compilation, the marola-sea fine-tune and the benchmark gate |
| [marola-oods](https://github.com/marola-dev/marola-oods) | The Open Ocean Data Store |
| [marola-devkit](https://github.com/marola-dev/marola-devkit) | The shared dev tooling, hooks, workflows and Claude Code plugin |
