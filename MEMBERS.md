## Adding or changing a member

One row per person, in a pull request to this repo. `Name` is `Family, Given`, as Zenodo writes
it; `ORCID` and `GitHub` are links, or empty. Change `.zenodo.json` in
[marola-dev/marola](https://github.com/marola-dev/marola) in step, so the next release credits the
same people, and bump `site/members.version` in marola-site so the page shows the change.
