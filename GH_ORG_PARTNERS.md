# GitHub organization partners

The GitHub organizations that are partners of marola, one row each, in alphabetical order. The
`GitHub` cell is the organization's handle, not a link, so a script can read it.

| Organization | GitHub | Website | What it is |
|---|---|---|---|
| OpenDiving | `opendiving` | https://opendiving.app/ | the open-source dive logbook, which lists marola among its partner apps |
| Ouroboric | `ouroboric-dev` | https://ouroboric.dev/ | Bruno Valério's open factory, which builds Yggdrasil |
| piabrota | `piabrota` | https://piabrota.art/ | the group of open-source projects, made in Rio de Janeiro, that hosts marola.dev |

## Adding or changing a partner

One row per organization, in a pull request to this repo, in alphabetical order. `Organization` is
the name the organization uses in public; `GitHub` is its handle on GitHub, which must resolve to
an organization ([orgs](https://github.com/orgs)); `Website` is its own site; and `What it is` is
one sentence, in the same words as the partners page on [marola.dev](https://marola.dev/partners.html).
A partner that is also an agent or a software fabric marola is built with belongs in `MEMBERS.md`
too, under `## Non-human`.
